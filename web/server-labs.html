الموقع العام يعمل على GitHub Pages. نسخة الخادم الخاص تضيف جلسات حساب مستقلة وصفحة متعلّم على أصل آخر لتجارب CSRF وCORS الفعلية.

خيار GitHub Codespaces

المستودع يحتوي إعداد تشغيل جاهز. افتح Code ← Codespaces ← Create codespace من المستودع، وانتظر تجهيز النسخة، ثم افتح منفذي 4173 و4174 من Ports وأبقِهما Private. افتح المنفذ الثاني مرة بحساب GitHub نفسه إذا طلب المصادقة، ثم ارجع للأكاديمية.

افتح المستودع

يحتاج حساب GitHub، والحصة المجانية شهرية ومحدودة وليست استضافة دائمة لكل الطلاب. GitHub Free يتضمن 120 core-hours و15 GB-month. راقب Usage وأوقف البيئة عند الانتهاء.

حدود Codespaces الرسمية

تشغيل محلي

npm ci --ignore-scripts
npm run prepare:practice
python server_labs/server.py

افتح http://127.0.0.1:4173 ثم مختبر CSRF أو CORS ← جلسات المتصفح. حسابا الباحث والمستخدم بيانات تدريبية؛ الصفحة المؤلفة على منفذ 4174. هذه تجربة اختلاف أصل، ولا تثبت تجاوز SameSite.

ما الذي يعمل فعلياً؟

  • كوكيز HttpOnly وجلسات مستقلة لكل حساب تدريبي.
  • طلبات متصفح من أصلين، وتعديل ملاحظة الحساب وتتبّع الطلبات على الخادم.
  • قراءة CORS عند عكس Origin بالضعيفة وحجب القراءة بالمُصلحة.

فحص المتصفح لـCORS يغطي عكس الأصل. حالات المطابقة الأخرى تظل نماذج سياسة منفصلة. سلوك الكوكيز يعتمد على إعداد المتصفح والوكيل السحابي؛ الموقع العام لا يدّعي تشغيل آلة سحابية.
