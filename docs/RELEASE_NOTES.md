First Android preview of Between Bytes Academy.

- Native Arabic Android interface (Android 8+).
- Shared curriculum: 96 guided security cases and six foundation lessons.
- Offline lessons, end-of-module quizzes, progression, XP and study streaks.
- No ChatGPT account required to install or study.
- Optional Academy API connection remains available in the native account screen.

This is a debug-signed test build. Compilation, Android lint and API tests run in CI; a physical-device runtime test is still required. Guided cases do not execute vulnerable servers. Progress is local unless an Academy API is configured.
