## تجربة الويب الحالية

`web/index.html` يستعيد واجهة المستودع الأصلية: 15 مختبراً و108 حالات مفتوحة، حقول قابلة للتعديل، محرر HTTP، إعادة إرسال ومقارنة، أدوات ترميز، قراءة حالة المورد وتصدير الدليل. مسار الويب القديم أزيل، و`web/learn.html` يعيد التوجيه إلى المختبرات الحالية. لكل موضوع أداة دخول مناسبة: متصفح وDOM، ورشة SQL/JSON/قالب، محرر JWT، محطة HTTP محلية، أو تطبيق وفاحص طلبات. المصدر وتتبع أسطر التنفيذ وPython أدوات إضافية اختيارية.

التنفيذ يستخدم **نفس محركات Python الأصلية** داخل Web Worker عبر Pyodide وSQLite. ملفات المحرك مرفقة في Android وتستضاف مع الموقع على GitHub Pages؛ لا يلزم Termux ولا CDN أثناء الاستخدام. النقل افتراضي محلي، ومعاينات XSS تعمل داخل iframe معزول. تجارب CSRF/CORS عبر خادمين لا يمكن تشغيلها كخدمات HTTP على GitHub Pages الثابت؛ تبقى على Pages نماذج سياسة واضحة. يوجد خادم خاص اختياري بجلستين وأصلين في `server_labs/`، وإعداد Codespaces محدود الحصة في `.devcontainer/`؛ ليس خادماً سحابياً منشوراً تلقائياً.

يُحمّل المحرك عند أول تنفيذ طلب فقط كي تبقى واجهة المختبرات سريعة؛ بعد التشغيل تبقى الحالة في ذاكرة العامل حتى إعادة تحميل الصفحة. Android يحتوي المحرك كاملاً؛ لذا حجمه الفعلي أكبر من نسخة الدروس السابقة (حوالي 69 KB). لا تُضاف ملفات لزيادة الحجم اصطناعياً.

```bash
npm ci --ignore-scripts --no-audit --no-fund
npm run prepare:practice
npm run test:wasm
python -m unittest discover -s tests -v
```

`prepare:practice` يجهز `web/vendor/pyodide/` ونسخة Android المولّدة `app/src/main/assets/web/`. المجلدان غير متتبعين؛ CI يبنيهما من الحزمة المثبتة بـpackage-lock. مصدر المحرك وحقوقه في `web/engine/` و`docs/THIRD_PARTY.md`.

**الاستضافة المطلوبة: GitHub Pages حصراً.** يحتاج المالك تفعيل Settings → Pages → Source → GitHub Actions مرة واحدة. ملف النشر جاهز، ويتحقق من الإعداد قبل المحاولة. لا ينشر هذا المشروع نسخة جديدة على Sites. الـPWA يخزن الواجهة ومحتوى الدروس، ويخزن ملفات المحرك عند جلبها؛ أول استخدام للمحرك على الويب يحتاج اتصالاً.

تنزيل Android: [Between-Bytes-Academy.apk](https://github.com/khdertaysh1/Between-Bytes-Android-/releases/download/v0.3.0/Between-Bytes-Academy.apk). إذا اعترض متصفح تطبيق المحادثة على APK، افتح الرابط في Chrome أو نزّل الملف من Assets في صفحة الإصدار. هو ملف APK وليس HTML أو ZIP مُعاد تسميته. النسخة debug وقد يتعارض توقيعها مع 0.1؛ إزالة التطبيق القديم تمسح تقدمه المحلي.

راجع [تقييم تجارب المختبرات والخدمات المجانية](docs/LAB_EXPERIENCE_REVIEW.md) و[المصدر وتتبع التنفيذ](docs/CODE_FLOW_WORKSPACE.md).

## مكونات Android والحسابات التجريبية

التفاصيل أدناه تصف مكونات الدروس وخدمة الحسابات التجريبية، وتحتاج تفعيل CLOUD_ACCOUNTS واستضافة API منفصلة للمزامنة. لا توجد حسابات ChatGPT للمختبرات.

منصة عربية لتعلّم أمن الويب. عميل Android أصلي وعميل Web/PWA يقرآن نفس المحتوى ويتصلان بنفس API للحسابات والتقدم.

## الموجود فعلياً

- شاشات Android أصلية للدروس والتقدم، مع WebView محلي معزول لمساحة العمل العملية؛ Android 8+.
- PWA عربية RTL متجاوبة، قابلة للتثبيت، مع تخزين الدروس وواجهة التطبيق للعمل دون اتصال بعد الزيارة الأولى.
- 15 وحدة تحليل أمني / 108 حالات، منها 96 مقتبسة من مشروع المستخدم Between-Bytes-Web-Labs، إضافة إلى 6 دروس تأسيسية.
- أسباب الثغرات، الطلب الطبيعي والمعدل، قراءة الأثر، مقتطفات الإصلاح، واختبار لكل وحدة.
- النجاح 80%، فتح تدريجي للمستويات، 150 XP لكل وحدة مرة واحدة، streak بتاريخ UTC.
- API تجريبي للحسابات وكلمات المرور والجلسات والتقدم؛ الخادم يتحقق من الإجابات وترتيب الفتح ويمنع تكرار النقاط.
- Android يحفظ token بتشفير AES-GCM ومفتاح Android Keystore؛ الويب يستخدم HttpOnly SameSite cookie.
- إعادة إرسال محاولات الحساب المؤجلة عند المزامنة، مع التحقق مجدداً على الخادم. لا يُمنح streak بأثر رجعي لتواريخ يرسلها الجهاز.
- GitHub Actions للاختبارات وبناء debug APK وتشغيل Android Lint.

**هذا الإصدار يحتوي مساحة عمل عملية بمحرك أصلي داخل المتصفح، ولا ينشر خوادم ضعيفة إلى الإنترنت.** مختبرات التنفيذ الفعلي تبقى في [Between-Bytes-Web-Labs](https://github.com/khdertaysh1/Between-Bytes-Web-Labs). مفاتيح الاختبارات ضمن المحتوى العام للتعلّم؛ النتائج ليست شهادات أو تصنيفاً تنافسياً محمياً من الغش.

## تشغيل المنصة كاملة محلياً

Python 3.12، بدون مكتبات خارجية:

```bash
python backend/server.py --host 127.0.0.1 --port 8080
```

افتح `http://127.0.0.1:8080`. الحسابات تعمل هنا، ويخزن SQLite البيانات خارج web/. يجب إبقاء الاستماع محلياً أثناء التطوير. على Termux ثبت Python أولاً.

لاستضافة عامة، شغّل نفس الخدمة خلف reverse proxy يوفر HTTPS مع قرص دائم وقواعد وصول مناسبة؛ اضبط `ACADEMY_SECURE_COOKIE=1` و`ACADEMY_DB` لمسار التخزين الدائم. يلزم إضافة تأكيد البريد واستعادة كلمة المرور ومراقبة/نسخ احتياطي وحدود طلبات مشتركة قبل استقبال طلاب فعليين. حد المحاولات المرفق مؤقت داخل العملية ويعاد عند إعادة التشغيل. لا تفتح مختبرات Web Labs الضعيفة إلى الإنترنت.

**الويب العام يحفظ التقدم محلياً ويفتح بدون تسجيل دخول. ليس استضافة لخادم Python، ولا يعني أن الحسابات والمزامنة السحابية فُعّلت.**

## تشغيل Android وتنزيل APK

للتنزيل بدون دخول GitHub، استخدم رابط APK المباشر أعلاه. ولتنزيل نسخة بناء محددة: من تبويب Actions افتح `Academy checks and Android APK`، انتظر نجاح `quality` و`android`، ونزّل artifact باسم `Between-Bytes-Academy-debug-APK`. فك ZIP وثبّت `app-debug.apk`. هذه نسخة debug للاختبار، وليست إصدار متجر أو إصداراً موقّعاً بمفتاح توزيع إنتاجي. مفاتيح debug على runners مؤقتة؛ قد تحتاج إزالة النسخة قبل تثبيت بناء لاحق، مما يمسح تقدم الضيف. احتفظ بالحساب المتزامن عند توفر الخدمة.

تنشر CI إصدار GitHub Release عند نجاح البناء على main. لا تستبدل ملف إصدار موجود، حتى لا يتغير توقيعه بسبب مفاتيح debug المؤقتة. يجب زيادة versionName قبل إصدار Android جديد.

البناء اليدوي يتطلب JDK 17 وAndroid SDK 35 وGradle 8.9:

```bash
gradle :app:assembleDebug :app:lintDebug
```

من حسابي في Android اضبط أصل خدمة الأكاديمية HTTPS، مثلاً عنوان الخدمة التي تستضيف Python وPWA. ثم أنشئ حساباً أو استخدم نفس حساب الويب. التطبيق يرفض HTTP، وإعادة التوجيه، وتعطيل تحقق TLS. لا تضع رابط المعاينة الخاصة بديلاً عن API عام. حفظ أصل خدمة مختلف يتطلب تسجيل الخروج أولاً. تقدم الضيف يبقى محلياً ولا يدمج تلقائياً مع الحساب.

## مصدر المحتوى الواحد

- `shared/source-cases.json`: الحالات الأصلية (نسخة ثابتة من كتالوجي المختبرات بتاريخ إعداد الإصدار).
- `tools/build_content.py`: يضيف التأسيس ويبني ترتيب الوحدات والاختبارات.
- `shared/catalog.json`: عقد المحتوى القانوني لكلا العميلين وAPI.
- `web/catalog.json` و`app/src/main/assets/catalog.json`: نسخ بناء مطابقة بايتياً، تفحصها CI.

```bash
python tools/build_content.py
python -m unittest discover -s tests -v
node --check web/app.js
node --check web/sw.js
```

يحصل Android على نسخة المحتوى الأحدث من `/api/catalog` عند المزامنة ويحتفظ بها بعد إغلاق التطبيق. PWA تحدث الأصول عند الاتصال وتستخدم الذاكرة المخبأة عند الانقطاع. ترقية schema تتطلب تحديث العميل.

## API v1

| المسار | الوظيفة |
|---|---|
| `GET /api/health` | حالة الخدمة والإصدار |
| `GET /api/catalog` | المحتوى المشترك schemaVersion=1 |
| `POST /api/register` | name/email/password (12–256 محرفاً) |
| `POST /api/login` | email/password |
| `GET /api/me` | ملف الحساب والتقدم المعتمد |
| `POST /api/attempt` | event UUID، lab ID، answers (فهرس الاختيار لكل سؤال) |
| `POST /api/logout` | إلغاء الجلسة الحالية |

Android يرسل `X-Academy-Client: android` عند المصادقة ليتلقى bearer token. الويب يتلقى cookie فقط. جميع عمليات تغيير الحالة JSON وبنفس Origin؛ لا يوجد CORS مفتوح. الجلسات تنتهي بعد 7 أيام وتخزن كـSHA-256 على الخادم. كلمات المرور PBKDF2-HMAC-SHA256 مع salt مستقل و600000 دورة. لا تحفظ كلمات المرور في العميل.

## تنظيم المستودعات

هذا commit يضع عميل Android والمصدر المشترك وخادم المنصة وPWA في المستودع المتاح حالياً حتى تكون النسخة قابلة للبناء والتجربة دون انتظار إنشاء مستودع آخر. عند توفير `Between-Bytes-Academy` تُنقل إليه `web/` و`backend/` والمحتويات القانونية، وينشر إصدار محتوى versioned تستخدمه CI الخاصة بمستودع Android. لا تنشئ نسختين قابلتين للتحرير من الدروس. `Between-Bytes-Web-Labs` يبقى مستقلاً دون تعديل أو حذف.

## حدود الإصدار

- لا توجد استضافة API عامة مفعّلة تلقائياً، والواجهة تعمل محلياً دون طلبات حسابات افتراضية، ولا خدمات دفع أو مفاتيح خارجية.
- لا توجد استعادة كلمة المرور/تأكيد البريد/لوحة إدارة أو تشغيل حاويات مختبرات بعيدة.
- تقدم الضيف قابل للتعديل محلياً؛ الخادم يعيد تقييم المحاولات عند استخدام الحساب.
- زمن streak هو UTC؛ لا توجد streak freeze أو تعويض أيام في هذا الإصدار.
- محاولات الحساب دون اتصال مؤقتة حتى يقبلها الخادم؛ API غير المصرح أو غير المتوافق يحتاج إعادة تسجيل الدخول/المراجعة.


### تحسينات 0.3.0

- مختبرا JWT (HMAC فعلي بمفتاح تدريبي معلن) وMass Assignment؛ 12 حالة جديدة، مع طلب سليم وأثر وحماية لنفس المدخل.
- حفظ تلقائي لمسودة JSON ونوع النسخة والملاحظات لكل حالة، واستكمال آخر تجربة وفلترة الحالات غير المكتملة. لا تحفظ المسودة حالة قاعدة المحرك أو جلسة المعاينة.
- شريط خطوات إثبات، وأداة فك JWT دون ادعاء التحقق من توقيعه، وعرض حالة API قبل التعديل وبعده.
- التخزين المؤقت أولاً للملفات الثابتة بدلاً من انتظار الشبكة عند كل طلب؛ زر لتجهيز المحرك وفحص ملفات التشغيل المتاحة دون إنترنت. مسح بيانات المتصفح يزيل التخزين.
- نفس المحتوى الإضافي في الدروس والاختبارات الأصلية وAndroid. شريط تحميل WebView ومعالجة توقف عملية العرض دون تخفيف عزل الشبكة.
